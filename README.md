## ✨ Возможности

- **Широкая поддержка форматов**: MP4, MOV, MKV, AVI, WebM, WAV, MP3, M4A, FLAC, AAC.
- **Исправление v18 (Action Fix)**:
  - **Восстановлена главная кнопка**: исправлена отрисовка кастомной кнопки `AnimatedPrimaryButton` (устранён сбой отсутствия импорта `QFont`). Текст и иконка отображаются кристально чётко.
  - **Диагностический отклик кнопки**: кнопка теперь остаётся активной для клика даже при временном отсутствии бинарников FFmpeg — при нажатии выводится информативное диагностическое окно с подсказкой, как исправить окружение.
  - **Блокировка только на время задачи**: кнопка деактивируется исключительно во время выполнения активного фонового процесса экспорта или анализа.
- **Надёжный движок v17 (Engine Reliability)**:
  - **Двухпроходная нормализация громкости (Two-pass EBU R128)**: первый проход замеряет интегральную громкость, динамический диапазон (LRA) и True Peak, второй проход производит точную подгонку под целевые -16 / -14 / -12 LUFS.
  - **Безопасное удаление пауз**: алгоритм строит строгое пересечение акустической тишины (FFmpeg `silencedetect`) и участков отсутствия речи (Silero VAD), предотвращая случайное обрезание окончаний слов и вдохов.
  - **Отменяемые процессы и реальный прогресс**: фоновые задачи (экспорт, построение формы волны, обработка) можно мгновенно прервать в любой момент кнопкой «Отмена».
  - **Атомарный экспорт файлов**: результат пишется во временный файл в целевой директории и подменяется только при 100% успехе, исключая повреждение данных.
  - **Пиковый лимитер с потолком -1.5 dBFS**: скорректировано авто-усиление лимитера для предотвращения интерсэмплового клиппинга при сжатии в AAC/MP3.
  - **Silero VAD через ONNX**: детектор речи работает через быстрый и легковесный `onnxruntime` без необходимости установки тяжеловесного PyTorch.
  - **Тестовое покрытие**: 18 автоматических модульных тестов, охватывающих экспортёр, процессор, регрессии интерфейса, детекцию пауз и выбор кодеков.
- **Стеклянный интерфейс (Glass UI)**:
  - Плитка «+» в зоне Drag & Drop открывает проводник в 1 клик.
  - Кнопка «Убрать файл» для мгновенного сброса рабочей области.
  - Скруглённые кнопки управления окном (свернуть, развернуть, закрыть) с плавной анимацией.
  - Встроенный асинхронный установщик AI-модулей прямо из диалога настроек.
  - Нативные плавные анимации и эффекты Windows 11 (DWM Mica / Acrylic).
  - История недавних файлов (Recent Files).
- **Интерактивный плеер и визуализация**:
  - Анимированная волна звука (Waveform) со шкалой времени и курсором воспроизведения.
  - Режим «До / После» (A/B тестирование) с плавным переключением на лету.

## 🚀 Быстрый старт

### Вариант 1. Запуск в 1 клик (рекомендуется)
Просто дважды кликните по файлу:
```bat
run_windows.bat
```
Скрипт автоматически создаст локальное виртуальное окружение `.venv`, установит зависимости и запустит приложение.

### Вариант 2. Ручной запуск
```bat
# 1. Создать и активировать окружение
python -m venv .venv
.venv\Scripts\activate

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить
python main.py
```

## ⚙️ Требование к FFmpeg

Для работы обработки звука и видео требуются утилиты **FFmpeg** и **FFprobe**.

Они могут быть:
1. Добавлены в системный `PATH` Windows.
2. Или помещены локально в папку `bin/`:
   ```text
   bin\ffmpeg.exe
   bin\ffprobe.exe
   ```

## 🧠 Дополнительные AI-модули (опционально)

По умолчанию обработка использует встроенные быстрые алгоритмы FFmpeg (`afftdn` для шумоподавления, `silencedetect` для пауз).

Для максимального студийного качества можно включить:
- **Silero VAD** (нейросетевой детектор речи через ONNX);
- **DeepFilterNet** (нейросетевое удаление сложных шумов и реверберации).

Установить их можно:
1. **Прямо из приложения**: откройте «Настройки» ⚙️ и нажмите «Установить AI компоненты».
2. **Либо через батник**:
   ```bat
   install_ai_windows.bat
   ```

Скрипт скачивает проверенную модель Silero VAD v6.2.1 ONNX и нативный бинарник `deep-filter.exe` v0.5.6 с проверкой контрольных сумм SHA-256 (PyTorch не требуется).

## 📊 Граф обработки звука

```text
Входной файл (видео / аудио)
   │
   ├─► Опциональный анализ пауз:
   │      ├─ FFmpeg silencedetect -> участки акустической тишины
   │      └─ Silero ONNX VAD      -> участки отсутствия речи
   │            Строгое пересечение -> безопасные паузы к удалению
   │
   ├─► Опционально: нейросеть DeepFilterNet (только для речи)
   │
   ├─► Фильтр высоких частот (High-pass 70 Гц)
   ├─► FFmpeg afftdn (если выключен DeepFilterNet)
   ├─► Эквалайзер присутствия голоса (~3 кГц)
   ├─► Мультиполосный компрессор
   │
   ├─► Двухпроходный EBU R128:
   │      ├─ Проход 1: измерение интегральной громкости, LRA, TP
   │      └─ Проход 2: точная нормализация под целевые LUFS
   ├─► Ресемплинг студийного качества (48 кГц)
   └─► Пиковый лимитер (-1.5 dBFS ceiling без ложного авто-гейна)
          │
          ▼
   Атомарное сохранение (MP4 / M4A / WAV)
```

## 🧪 Запуск тестов

Тестирование движка и интерфейса выполняется командой:

```bat
python -m unittest discover -s tests -v
```

Набор включает **18 автоматических тестов**:
- Атомарность сохранения и отмена экспорта без повреждения файлов (`test_exporter.py`).
- Двухпроходный Loudnorm, цепочка мастеринга, безопасность Voice+Music, лимитеры (`test_processor.py`).
- Определение и выбор кодеков Windows Media Foundation (`test_tools.py`).
- Алгоритмы объединения пауз и вероятности речи Silero VAD (`test_vad.py`).
- Регрессионные тесты импорта QFont и доступности кнопки диагностики (`test_ui_regressions.py`).

## 💻 Технические детали Glass UI

- Приложение разработано на нативном **Qt Widgets (PySide6)** без использования веб-движков, Electron или Chromium.
- Для безрамочного оформления используется `Qt::FramelessWindowHint`.
- Перемещение и изменение размеров окна вызывают нативные системные методы `QWindow::startSystemMove()` и `QWindow::startSystemResize()`.
- На **Windows 11 (сборка 22621+)** задействуется нативный DWM API с атрибутом `DWMWA_SYSTEMBACKDROP_TYPE` и параметром `DWMSBT_TRANSIENTWINDOW` (Desktop Acrylic), а также системная тёмная тема.
- На более ранних версиях Windows автоматически включается аппаратный полупрозрачный матовый Qt-фоллбэк.
